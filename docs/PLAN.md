# 기획 요약

## 한 줄 정의

우리은행은 청소년의 소비를 진단까지 해 준다. 이 엔진은 그 진단을 학습과 미션으로 연결하고, 가상투자에서 실수한 순간을 배우는 순간으로 바꾼다.

## 적용처

- 우리은행 우리틴틴 + 청소년 마이데이터(2026.04 출시, 만 14세 이상)
- 우리은행에 있음: 용돈 관리, 틴틴카드, 카드·예금 내역 통합, 용돈·저축 진단, 소비 카테고리 분석
- 우리은행에 없음: 금융교육, 모의투자, 미션 → 이 엔진이 채운다

## 대표 기능 ① Mistake-to-Lesson

1. 감지: 가상투자에서 실수 패턴 감지 (코드 규칙)
   - 급등 추격: 직전 거래일 대비 +10% 이상 오른 종목을 당일 매수
   - 몰빵: 한 종목 비중 60% 이상
   - 근거 없음: 투자 일지가 비었거나 10자 미만
2. 질문: LLM이 "왜 샀는지" 질문을 만들고, 학생 답을 FOMO / 과신 / 근거 부족 / 해당 없음 중 하나로 분류
3. 학습: 분류에 맞는 `content/concepts/` 콘텐츠를 골라 학생 수준에 맞게 설명
4. 재도전: 같은 패턴이 다시 감지되면 과거 기록을 언급하며 근거를 묻는다
5. 기록: 학생 답과 분류 결과를 파일에 저장한다 (부모 리포트의 재료, 부모에게 답 원문은 보여 주지 않음)
- 결과(수익률)가 아니라 과정을 평가한다. 오른 경우에도 같은 패턴이면 똑같이 짚는다.

## 대표 기능 ② AI 행동 미션 루프

1. 진단: 소비·저축·가상투자 기록에서 지표 계산(코드) → LLM이 "잘하고 있는 것" 1~2개와 "이번 주 연습할 것" 1~2개를 키워드로 고르고 한 문장으로 설명
   - 학생에게는 점수 없이 키워드와 한 문장만 보여 준다. 예: 잘하는 것 "근거 적기", 연습할 것 "한 종목 쏠림"
2. 미션: 학생 상황에 맞는 이번 주 미션 문장 생성
3. Simulation: 목표까지 대안 A/B/C별 예상 기간 계산(코드) → 학생이 선택
4. Replay: 주말에 미션 수행률, 목표 달성 예상일 변화 계산(코드) → LLM이 해석
5. 재조정: 수행률에 따라 다음 주 미션 난이도 조정

## 지표 (행동 변화 측정)

- 한 종목 최대 비중
- 근거 없는 매수 비율
- 같은 실수 재발률
- 미션 수행률, 저축 목표 달성률

## 포함 기능: 행동 기반 포인트 보상 + 캐릭터 육성

- 포인트를 받는 행동: 미션 수행, 근거 있는 일지, 저축 목표 달성
- 수익률·지출 금액과는 연결하지 않는다. 대충 쓴 일지(공백 제외 10자 미만)는 포인트 없음
- 하루 적립 상한이 있다. 현금화할 수 없다
- 캐릭터: 포인트로 먹이를 주면 단계별로 자란다. 미션을 못 해도 아프거나 죽지 않는다
- 쓰는 곳: 편의점 쿠폰 같은 즉시 보상. 데모는 실제 발급 없이 가상 쿠폰 교환 화면까지

## 포함 기능: 부모 AI 코칭 리포트

- 보여 주는 것: 저축률 변화, 미션 수행률 변화, "이번 달 부모 미션"
- 보여 주지 않는 것: 아이의 투자 일지 원문, 학생 답 원문, 내부 점수

## 보류 (사용자가 말하기 전까지 만들지 않음)

Skill Unlock(실전 소수점 투자 해금), 학교·반 리그, 효과 측정 대시보드, 연령 확대

## 기능별 완료 기준

- 9: 새 화면 '실전 준비 단계' + 홈 메뉴. 2단계(실제 시세 연습) 조건: 최근 매수 3번 모두 일지 10자 이상, 가장 큰 종목 비중 60% 미만, 돌아볼 매수가 있으면 실수에서 배우기 1번 + 나만의 규칙 1개. 3단계(실전 준비 완료) 조건: 미션 해낸 주 2주 이상, 매수 후 5일 안에 판 적 없음, 실제 시세에서 이유를 적은 매수 1번 이상. 조건을 채우면 버튼으로 열고 `unlocks.csv`에 남아 다시 잠기지 않는다. 2단계 전에는 투자연습 시세 스위치가 잠긴다(시연 모드는 잠금 없음). 3단계는 보호자 승인 요청 시안이며 실제 주문과 연결하지 않는다. 수익률·점수는 기준과 화면에 없다. 부모 리포트에 지금 단계 표시. 서연(균형형)만 처음부터 2단계를 열 수 있다.
- 11: 사이드바 '데모 설정'의 링크로 들어가는 교사·운영자용 화면. 학생 전체의 주차별 실수 패턴 매수 비율(급등 추격·몰빵·근거 없음), 미션 달성률, 저축률, 원함 지출 비율(처음 주 → 최근 주), 앱 활동(돌아보기·규칙·1분 점검·개념 질문·단계 분포), 콘텐츠 추가 후보(카드 없어 못 답한 질문), 학생별 행동 횟수. 수익률·역량 점수·학생 답 원문은 없다. 가상 데이터라 통계적 효과가 아니라는 안내를 화면에 둔다. 계산은 `engine/effect.py`.
- 20: 새 화면 '마이데이터 연결' + 홈 메뉴. 팀이 카드 소비 통계로 만든 가상 1,000명(`data/reference/virtual_accounts.csv`) 중 19세(성인)를 뺀 783명. 약한 역량 4가지로 예시를 고르고 '불러오기'를 누르면 학년·용돈·월평균 지출·목표, 이번 주 연습할 것(+개념 카드), 목표까지 계산(매달 필요 금액, 남는 돈, 지금 페이스 기간)을 보여 준다. 만 14세 미만은 보호자 동의 안내. AI는 첫 인사만 쓰고 facts에 없는 숫자·성향 이름은 막는다. 실제 마이데이터와 연결하지 않는다.
- 21: 새 화면 '자산 키우기 게임' + 홈 메뉴 (교수님 피드백: 자산을 지키고 불리는 방법을 AI로). 40초 동안 떨어지는 단어 25개(좋은 습관 13, 나쁜 습관 12) 중 좋은 습관만 바구니로 받는다. 단어마다 개념 카드 연결 (새 카드: 비상금, 빚투, 원금 보장 고수익). 2번 이상 보인 실수 패턴의 개념 단어는 2배 자주. 코인(시작 10,000, 좋은 +1,000, 나쁜 -1,500)은 게임 안 점수로만 쓰고 평가·포인트와 연결하지 않는다. 끝나면 AI 코치 한마디(게임 결과 + 실제 가상투자 행동, facts 밖 숫자 차단). 15,000 미만이면 1분 복습(개념 카드 + AI 퀴즈 2 + 카드 확인 문제 1)을 모두 맞혀야 다시 도전. 복습을 모두 맞히면 30P (`game_reviews.csv`, 같은 날 같은 개념 1번, 하루 상한 200P 안에서). 게임 코인은 포인트와 연결하지 않는다. 게임 화면은 `components/catch_game/index.html`.
- 1: `data/students/`에 성향이 다른 학생 3명(몰빵형, 저축 실패형, 균형형)의 4주치 데이터. `pytest`로 형식 검증.
- 2: 종목 선택 → 매수/매도 → 일지 입력 → 보유 현황 표시. 일지 없이 매수 가능하되 빈 일지로 저장.
- 3: 용돈 입금, 쓰기/모으기/투자연습 비율 설정, 지출 내역 표시.
- 4: 최소 개념 6개 (FOMO, 분산투자, 과신, 목표저축, 필요 vs 원함, 복리). 형식은 `content/concepts/_TEMPLATE.md`.
- 5: 학생 3명 데이터로 실행 시 몰빵형에게만 몰빵 패턴이 감지되고, 질문 → 분류 → 콘텐츠 설명까지 화면에 표시.
- 5-1: 5번 화면에서 학생이 답하면 질문·답·분류 결과·고른 개념이 `data/students/` 아래 파일에 한 줄로 저장된다. 앱을 다시 켜도 지난 기록이 화면에 보인다. 8번 부모 리포트가 이 파일을 읽는다 (부모 화면에는 답 원문을 보여 주지 않는다).
- 6: 1주차 진단 → 미션 → 대안 선택 → 2주차 Replay → 재조정 미션까지 한 사이클이 화면에서 돈다.
  - 진단 결과는 학생에게 점수 없이 보여 준다. 형식: "잘하고 있는 것" 키워드 1~2개 + "이번 주 연습할 것" 키워드 1~2개 + 한 문장 설명.
  - 예: 잘하는 것 "근거 적기", 연습할 것 "한 종목 쏠림".
- 7: 포인트 적립 → 캐릭터 먹이 주기 → 단계별 성장 → 가상 쿠폰 교환까지 화면에서 된다.
  - 적립 기준: 미션 수행, 근거 있는 일지, 저축 목표 달성. 수익률·지출 금액과는 연결하지 않는다.
  - 대충 쓴 일지는 포인트 없음 (기준: 5번 "근거 없음"과 같은 공백 제외 10자 미만).
  - 하루 적립 상한이 있다. 포인트는 현금화할 수 없다.
  - 캐릭터: 포인트로 먹이를 주면 단계별로 자란다. 미션을 못 해도 아프거나 죽지 않는다 (성장이 멈출 뿐).
  - 쿠폰: 편의점 쿠폰 같은 즉시 보상. 데모에서는 실제 발급 없이 가상 쿠폰 교환 화면까지만.
- 8: 부모 화면에 저축률 변화, 미션 수행률 변화, "이번 달 부모 미션"만 보여 준다.
  - 아이의 투자 일지 원문, 5번 학생 답 원문, 내부 점수는 보여 주지 않는다.

- 13: 투자연습 탭에 "실제 시세 / 시나리오" 전환이 있고 기본값은 시나리오.
  - 실제 시세 모드: 고정 목록(15개 이내, docs/에 기록)의 실제 국내 종목과 가격, 기준 시각이 보인다. 거래는 가상 투자금(실제 시세 모드는 200만 원, 시나리오는 100만 원)으로만, 실제 주문 기능 없음.
  - 공식 API만 사용 (크롤링 금지). 키는 로컬 `.env`, 배포는 Streamlit Secrets에만 있고 GitHub에 없다.
  - 같은 종목 시세는 5분간 저장해 재사용한다.
  - 장이 닫혀 있으면 "마지막 가격"과 기준 시각을 보여 준다.
  - API 실패 → "시세를 불러오지 못했어요" + 마지막 저장값, 저장값도 없으면 시나리오 데이터.
  - 5번 감지(급등 추격·몰빵·근거 없음)가 실제 시세 모드에서도 같은 기준으로 동작한다.
  - 시나리오 모드로 바꾸면 민지 시연(5·6번, 시연 모드 저장 응답)이 이전과 똑같다.
  - pytest 전부 통과, 장 마감·API 실패를 흉내 낸 테스트 포함.

  - AI는 판단을 따라 2~3문장 회고 + "다음에 이어 갈 것" 1문장만 쓴다. facts에 없는 숫자(단위 포함)를 쓰면 실패로 보고 다시 묻는다.

  - 미션 목표(코드): 지난주 편의점·카페·디저트 금액에서 쉬움 10% / 보통 20% / 어려움 30% 줄인 금액(천 원 단위 내림, 최소 1,000원) 이하. 주말 Replay에서 그 주 금액으로 판정.

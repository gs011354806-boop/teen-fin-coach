## 기능별 완료 기준

- 1: `data/students/`에 성향이 다른 학생 3명(몰빵형, 저축 실패형, 균형형)의 4주치 데이터. `pytest`로 형식 검증.
- 2: 종목 선택 → 매수/매도 → 일지 입력 → 보유 현황 표시. 일지 없이 매수 가능하되 빈 일지로 저장.
- 3: 용돈 입금, 쓰기/모으기/투자연습 비율 설정, 지출 내역 표시.
- 4: 최소 개념 6개 (FOMO, 분산투자, 과신, 목표저축, 필요 vs 원함, 복리). 형식은 `content/concepts/_TEMPLATE.md`.
- 5: 학생 3명 데이터로 실행 시 몰빵형에게만 몰빵 패턴이 감지되고, 질문 → 분류 → 콘텐츠 설명까지 화면에 표시.
- 5-1: 5번 화면에서 학생이 답하면 질문·답·분류 결과·고른 개념이 `data/students/` 아래 파일에 한 줄로 저장된다. 앱을 다시 켜도 지난 기록이 화면에 보인다. 8번 부모 리포트가 이 파일을 읽는다 (부모 화면에는 답 원문을 보여 주지 않는다).
- 6: 1주차 진단 → 미션 → 대안 선택 → 2주차 Replay → 재조정 미션까지 한 사이클이 화면에서 돈다.
  - 진단 결과는 학생에게 점수 없이 보여 준다. 형식: "잘하고 있는 것" 키워드 1~2개 + "이번 주 연습할 것" 키워드 1~2개 + 한 문장 설명.
  - 예: 잘하는 것 "근거 적기", 연습할 것 "한 종목 쏠림".
- 7: 포인트 적립 → 캐릭터 먹이 주기 → 단계별 성장 → 가상 쿠폰 교환까지 화면에서 된다.
  - 적립 기준: 미션 수행, 근거 있는 일지, 저축 목표 달성. 수익률·지출 금액과는 연결하지 않는다.
  - 대충 쓴 일지는 포인트 없음 (기준: 5번 "근거 없음"과 같은 공백 제외 10자 미만).
  - 하루 적립 상한이 있다. 포인트는 현금화할 수 없다.
  - 캐릭터: 포인트로 먹이를 주면 단계별로 자란다. 미션을 못 해도 아프거나 죽지 않는다 (성장이 멈출 뿐).
  - 쿠폰: 편의점 쿠폰 같은 즉시 보상. 데모에서는 실제 발급 없이 가상 쿠폰 교환 화면까지만.
- 8: 부모 화면에 저축률 변화, 미션 수행률 변화, "이번 달 부모 미션"만 보여 준다.
  - 아이의 투자 일지 원문, 5번 학생 답 원문, 내부 점수는 보여 주지 않는다.

- 13: 투자연습 탭에 "실제 시세 / 시나리오" 전환이 있고 기본값은 시나리오.
  - 실제 시세 모드: 고정 목록(15개 이내, docs/에 기록)의 실제 국내 종목과 가격, 기준 시각이 보인다. 거래는 가상 투자금으로만, 실제 주문 기능 없음.
  - 공식 API만 사용 (크롤링 금지). 키는 로컬 `.env`, 배포는 Streamlit Secrets에만 있고 GitHub에 없다.
  - 같은 종목 시세는 5분간 저장해 재사용한다.
  - 장이 닫혀 있으면 "마지막 가격"과 기준 시각을 보여 준다.
  - API 실패 → "시세를 불러오지 못했어요" + 마지막 저장값, 저장값도 없으면 시나리오 데이터.
  - 5번 감지(급등 추격·몰빵·근거 없음)가 실제 시세 모드에서도 같은 기준으로 동작한다.
  - 시나리오 모드로 바꾸면 민지 시연(5·6번, 시연 모드 저장 응답)이 이전과 똑같다.
  - pytest 전부 통과, 장 마감·API 실패를 흉내 낸 테스트 포함.
